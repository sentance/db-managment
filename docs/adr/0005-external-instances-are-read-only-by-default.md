# ADR 0005: Внешние инстансы по умолчанию только для чтения

**Статус:** принято, 2026-10-21

## Решение
- Регистрация external-инстанса выполняет только подключение и `select version()`.
- Режимы: `MONITOR_ONLY` (по умолчанию) и `MANAGE_OBJECTS` (step-up). Второй разрешает только CREATE/ALTER/DROP баз и ролей.
- Независимо от режима pgcp никогда не перезапускает, не обновляет и не переносит внешний сервер, не меняет `ALTER SYSTEM`, `archive_command` и pg_hba.
- Защита по умолчанию `PRODUCTION`. «Удаление» external-инстанса только снимает его с учёта в pgcp.
- Роли суперпользователей и роль, под которой подключается pgcp, нельзя менять из UI.

## Рекомендация
Для мониторинга создайте на сервере вручную отдельную роль:
```sql
create role pgcp_monitor login password '...';
grant pg_monitor to pgcp_monitor;
```
